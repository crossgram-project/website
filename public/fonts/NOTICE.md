# Bundled fonts

Both families are self-hosted from this directory (woff2, latin + latin-ext subsets):

| Family | Files | License |
| --- | --- | --- |
| Host Grotesk (variable 300–800) | `host-grotesk-latin*.woff2` | SIL Open Font License 1.1 |
| Fragment Mono (400) | `fragment-mono-latin*.woff2` | SIL Open Font License 1.1 |

Chinese text falls back to the system sans-serif stack (`Noto Sans SC`, `PingFang SC`,
`Microsoft YaHei`). The fonts are distributed under the SIL Open Font License 1.1; the full
license text is available at <https://openfontlicense.org/open-font-license-official-text/>.
