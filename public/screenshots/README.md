## 截图规则

- 使用一致的深色主题、窗口尺寸和缩放比例。
- 隐去手机号、Token、IP、用户名、群号与私人消息。
- 不要在图片外部自行加圆角、阴影和透视，网站会统一处理。
- 关键内容避开四周约 6% 的安全区，以免响应式裁切。
- WebP 建议质量 82–88；首页首图尽量控制在 350 KB 内，其余单张尽量控制在 250 KB 内。
